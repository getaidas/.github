# Aidas

**A local-first workspace for API development and integration debugging.**

Aidas is being built for developers who spend their day sending API requests, switching between environments, and tracing why an integration behaves differently in staging and production.

## What we’re building

- **An account-free desktop workflow.** Organize requests and environments and run them from your machine.
- **Workspaces that fit into Git.** Keep shared requests and environment definitions alongside your code so changes can be reviewed together.
- **Tools for integration debugging.** Inspect requests and responses and iterate on the calls that reproduce a problem.

Aidas is in development. Find out more at [getaidas.dev](https://getaidas.dev).
